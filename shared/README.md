# Shared documentation templates

Copy [hardware](templates/hardware.md), [slicer inventory](templates/slicer-profiles.md), [calibration record](templates/calibration-record.md) and [setup notes](templates/setup-notes.md) into the relevant printer directory for future records. Replace TBD only with a sourced fact. Existing printer records use the same fields.

Share review conventions and test methodology, not machine pins or universal tuned values. Templates contain no executable G-code. Check every proposed public addition using the [publication checklist](../docs/publication-safety.md).
